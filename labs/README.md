# Cybersecurity Labs

This folder contains hands-on lab documentation from my cybersecurity studies and independent practice.

Each lab will include:

- Objective
- Environment and tools
- Procedure
- Screenshots or evidence
- Results
- Security lessons learned

## Planned Lab Topics

- Wireshark traffic analysis
- Nmap network discovery and scanning
- Windows Active Directory and Group Policy
- Linux users, permissions, and system hardening
- Vulnerability scanning with OpenVAS or Nessus
- Web application testing with OWASP ZAP and Nikto
- DNS, DHCP, VLAN, VPN, and subnetting exercises
